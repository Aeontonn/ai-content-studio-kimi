# AI Content Studio · Kimi skill

A Kimi skill (SKILL.md format) for planning, writing, editing and repurposing social media
content: Instagram Reels, Stories, carousels, TikTok, YouTube Shorts and email newsletters,
with a visual weekly calendar and a brand memory. Works in English and Chinese.

一个 Kimi 技能：规划、撰写、剪辑和一稿多用社交媒体内容（Reels、快拍、轮播图、TikTok、
YouTube Shorts、邮件），带可视化周日历和品牌记忆。支持中文和英文。

## Install / 安装

- **kimi.com:** paste this repository's URL into a Kimi chat: "Please install this skill: <URL>".
  在 Kimi 对话中发送：「请安装这个技能：<本仓库链接>」。
- **Kimi Work:** download this repository as a ZIP and upload it under Skills.
  下载本仓库的 ZIP，在 Kimi Work 的「技能」中上传。
- **Kimi Code:** clone into `~/.agents/skills/ai-content-studio-kimi`.
  克隆到 `~/.agents/skills/ai-content-studio-kimi`。

`SKILL.md` is at the repository root. Optional Python packages: `requirements.txt`,
`requirements-video.txt`. Examples are in `examples/` (Chinese set in `examples/zh/`).
